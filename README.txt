دعوت‌نامه دیجیتال نگار و حسین

نسخه انتشار GitHub Pages است و به PHP نیاز ندارد.
فرم تأیید حضور از طریق Formspree ثبت می‌شود و پاسخ‌ها در حساب Formspree و ایمیل میزبان قابل مشاهده‌اند.

نمونه لینک‌های مهمان:
همراه با عقد: index.html?name=جناب%20آقای%20نمونه%20و%20خانواده&tier=aqd&id=guest-001
فقط مراسم: index.html?name=دوست%20عزیزمان&tier=ceremony&id=guest-002

پیش از انتشار عمومی، فهرست مهمانان و شناسه‌های غیرقابل‌حدس جایگزین نمونه‌ها شود.
